데이터와 변수

정의
Variable

변수란 개체(행)마다 값이 달라지는 특성. 데이터는 표(행 = 개체, 열 = 변수)로 표현한다.

구분유형예시
정성적 (범주형)명목형 / 순서형성별, 등급, 만족도
정량적 (수치형)이산형 / 연속형점수, 키, 온도
예시

"중간고사 점수" → 수치형·이산형 · "전공 계열" → 범주형·명목형

확률이란

Definition

확률 = 사건이 일어날 가능성을 0~1 사이의 수로 표현. 모든 결과 확률의 합은 1.

$$P(\text{사건}) = \frac{\text{사건의 결과 수}}{\text{전체 결과 수}}$$
예시

주사위 짝수 눈 확률 = $\dfrac{3}{6} = 0.5$

출처: 확률과 통계, 교과서 p.24
